# THE FLY — Meshy reference

This is a 2D reference for generating the 3D asset, not a rigged model.
Use the single-character light-background image in Meshy Image to 3D.
The dark chamber illustration is a character identity reference, not the
preferred geometry-generation input. Do not upload a multi-view collage as if
it were one character.

Preserve the six limbs, separate wings, oversized graphite head, two fully
open glossy dark eyes, lime thorax band and small amber marker. Use a neutral
face for geometry reconstruction; expression belongs to later animation. Check generated geometry from
both sides: a good front render does not establish complete hidden anatomy.

The text in MESHY_PROMPT.txt is optional guidance for tools/settings accepting
an additional prompt. It is not an assertion that all Image-to-3D interfaces
accept this field.

Preferred handoff for the web integration: GLB with textures, plus rig when
available. Meshy's Smart Rig beta supports nonstandard creatures, but its
ready-made animation library does not currently support Smart Rig models.
The website integration must inspect the actual skeleton before promising
independent head, wing or limb animation.

Source checked: https://help.meshy.ai/en/articles/16231707-how-to-create-3d-animation-with-auto-rigging

Character/reference images were generated using the built-in image generation
tool. This is designed mascot art, not measured biological or neural telemetry.
